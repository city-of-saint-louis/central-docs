# Welcome to Central Docs

### Development Standards
The goal of Central Docs is to establish a single, authoritative set of standards that apply to all software development efforts conducted by or on behalf of the City of St. Louis.

### Living Documentation
Standards should not be conceived in a vacuum, nor should they be considered immutable. Our development standards are intended to facilitate, rather than restrict, the collaborative development experience. We encourage all city developers to play an active role in creating, maintaining, and implementing them.

### Best Practices
Some guidelines should be interpreted as "best practices" rather than true standards. Where present, these will be clearly indicated as such. 

It is also possible for something to be situationally mandatory. RepoA includes structured comments for some functions. RepoB enforces structured comments in its linter rules. Structured comments are a best practice for RepoA but a mandatory standard for RepoB.
